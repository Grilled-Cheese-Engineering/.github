# Grilled Cheese Engineering

Grilled Cheese Engineering was started by @JStudios6118 and @Lucasmoidel with the goal of making cool, useful hardware. This organization was created to make it easy to find and modify our work. We have build guides and firmware downloads in our repositories.

Thanks for checking us out!
